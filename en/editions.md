# Community and Enterprise editions

Sessage uses one shared task-management foundation. Enterprise extends that foundation with modules for structured intake, automation and cross-list oversight.

## At a glance

| Capability | Community | Enterprise |
| --- | :---: | :---: |
| Lists, tasks, comments and attachments | ✓ | ✓ |
| List, Kanban, table and calendar views | ✓ | ✓ |
| Labels | ✓ | ✓ |
| Email invitations and share links | ✓ | ✓ |
| AD/LDAP sign-in | ✓ | ✓ |
| REST API and mobile app | ✓ | ✓ |
| Native Android, iOS and Windows push notifications | — | ✓ |
| Portfolios and configurable dashboards | — | ✓ |
| Forms and custom fields | — | ✓ |
| Email intake | — | ✓ |
| Automations and webhooks | — | ✓ |
| Sharing with AD users and groups | — | ✓ |

## Community Edition

Community Edition is a standalone server licensed under EUPL-1.2. It covers everyday task management and collaboration and can be inspected, modified and operated on your own infrastructure.

Choose Community when you need a dependable shared task system and do not require Enterprise workflow modules. [Explore Community](./community/index.md).

## Enterprise Edition

Enterprise includes every Community capability and adds tools for organization-wide processes:

- portfolios that group related lists and inherit access roles;
- dashboards with key metrics, charts and task overviews;
- custom list fields and internal or public forms that create structured tasks;
- IMAP email intake that converts messages into tasks;
- automation rules and outbound webhooks;
- directory sharing with individual AD users and AD groups.
- optional native push notifications with anonymous or detailed lock-screen content and direct task navigation.

Choose Enterprise when requests must follow repeatable rules or leaders need a live view across multiple lists. [Explore Enterprise](./enterprise/index.md).

## Moving between editions

Both editions use the same core data model and clients. An organization can start with Community and enable Enterprise modules later without recreating existing lists and tasks. If an Enterprise license becomes invalid, Enterprise modules are disabled while Community data and functions remain available. Existing custom-field definitions and values are retained but hidden until Enterprise Forms is enabled again.
